# Índice de evidencia saneada — corte parcial 26/10/2026

Zona de interpretación: **America/Bogota**. Estas evidencias corresponden a **P1/P2 web y P3 API publicado/verificado**, con los límites de cada reporte. **No acreditan entrega final, aceptación integral ni interfaz clínica terminada. La auditoría integral del proyecto debe esperar a la versión final del equipo.** El [expediente de 94 criterios](../../expediente-auditoria-2026-10-26.md) conserva todos los criterios sin notas ni porcentajes de cumplimiento.

Cada archivo conserva el instante, revisión y entorno que evaluó. Un indicador `publicationVerified=false` de una prueba local no se cambia porque después haya publicación. Una restauración tiene su reporte independiente del manifiesto que creó el dump. Las comprobaciones HTTP, métodos JUnit, casos TestRail y métricas académicas son unidades distintas.
